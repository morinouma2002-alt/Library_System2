課題：図書館の貸出システム
作るもの
本（Book）と利用者（Member）がいます。

利用者には、学生（Student）と教員（Teacher）の2種類があります。

学生は3冊まで借りられる
教員は5冊まで借りられる
学生の貸出期間は7日
教員の貸出期間は14日
Library が、本の一覧と利用者の一覧を持ちます。

条件
Student と Teacher が共通の親クラス Member を持つ構成にする
貸出可能冊数と貸出期間は Member のメソッドをオーバーライドして切り替える
instanceof は使わない
貸出・返却のロジックは Library に書く
System.out は Main 側だけで使う
Library が持つリストを外から直接 add/remove できないようにする
提出前に答えられるようにすること
継承の向きはなぜこれで正しいのか
Library を Member の親にしなかった理由は何か
新しい利用者（例：職員）を追加するとき、どのファイルを変えればいいか
学習目的
is-a 関係を意識した継承設計
オーバーライドとポリモーフィズム
責務分離
カプセル化
